> 想第一时间读到新文章，又不想每次都打开网站、也不想被算法和广告打扰？用 **RSS 订阅** 就够了。这篇指南从零讲起，跟着做即可。

## 一、RSS 是什么

**RSS**（Really Simple Syndication，简易信息聚合）是一种"内容订阅格式"。

可以把它理解成：**博客对外提供的一份「最新文章清单」**，里面包含每篇文章的标题、摘要、发布时间和链接。这份清单会随新文章发布自动更新。

你不用逐个网站去翻，只要用一个叫 **RSS 阅读器** 的工具"盯着"这份清单，新文章一出现，阅读器就会自动把它送到你面前。

## 二、它是怎么工作的

整个过程只有三个角色，原理很简单：

| 角色 | 是谁 | 做什么 |
| --- | --- | --- |
| **内容源** | 本站 | 每次发布文章，自动生成并更新一份 XML 清单（就是 RSS 地址） |
| **阅读器** | 你安装的工具 | 按你设定的时间，定期去检查这份清单有没有变化 |
| **你** | 订阅者 | 在阅读器里集中阅读，看到标题感兴趣再点开原文 |

也就是说：

1. 你在阅读器里填入本站的 RSS 地址，完成"订阅"；
2. 阅读器记住这个地址，每隔一段时间自动访问一次；
3. 一旦发现清单里多了新文章，就把标题和摘要推送给你；
4. 你点开链接，跳到本站阅读全文。

**三个好处**：

- **不漏更**：不用惦记什么时候更新，新文章自动送到。
- **无广告、无算法**：只看你订阅的内容，没有推荐、没有信息流干扰。
- **一站聚合**：多个博客、新闻源都能放进同一个阅读器集中管理。

## 三、本站的 RSS 地址

本站由 Astro 生成静态 RSS，地址固定为：

```
站点域名/index.xml
```

例如（把域名换成你实际访问的本站地址）：

```
https://你的域名/index.xml
```

页脚右侧的 **RSS** 小图标，点击后打开的也是这个地址。你可以：

- **直接用浏览器打开**：能看到一串 XML 文本，说明地址有效（内容看着乱是正常的，那是给程序读的格式）；
- **复制这个地址**：用于下一步在阅读器里订阅。

> 小提示：整站文章用 `/index.xml`；如果想只订阅某个分类，可在分类页找对应的分类 RSS 地址。

## 四、如何订阅（三步）

### 第 1 步：选一个 RSS 阅读器

推荐几款常见、口碑好的（选一个即可）：

- **手机端**：Reeder（iOS / macOS）、NetNewsWire（iOS / macOS，免费）
- **电脑端**：Inoreader（网页版，免费起步）、Feedly（网页版）
- **国产 / 多端同步**：Follow、Tiny Tiny RSS（可自建）

按自己的设备挑一个，注册或安装好。

### 第 2 步：添加订阅源

在阅读器里找到 **「添加订阅 / Add Feed / 新建源」** 之类的按钮，然后把上面复制的地址粘进去：

```
https://你的域名/index.xml
```

确认后，阅读器会自动读取清单，列出本站最近的文章。

### 第 3 步：完成，等着收更新

订阅成功后，本站就出现在你的订阅列表里了。以后只要有新文章，阅读器会自动显示，你打开阅读器就能看到——不用再特意访问网站。

## 五、常见问题

**Q：填了地址，阅读器说"无法订阅 / 解析失败"？**
先确认地址是不是完整的 `https://.../index.xml`（别漏了 `index.xml`），可以先用浏览器打开验证。若仍失败，多为阅读器缓存问题，稍后重试或换个阅读器。

**Q：浏览器打开是一堆代码，是不是坏了？**
不是。RSS 本来就是给程序读的 XML 格式，浏览器只是原样显示文本。"能打开"恰恰说明地址正常。

**Q：订阅后能看到全文吗？**
默认显示标题和摘要，点开文章链接会跳到本站阅读完整内容。

**Q：会不会泄露我的隐私？**
RSS 是"拉取"模式：由你的阅读器去取内容，本站不需要知道你是谁，也不会向你推送任何东西。相比关注公众号、注册账户，它反而更清净。
